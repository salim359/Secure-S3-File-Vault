# Locket UI

Next.js app for the Secure S3 File Vault. Setup, env vars, and the rest of the project live in the [root README](../README.md).

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000. Set `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_COGNITO_CLIENT_ID`, and `NEXT_PUBLIC_AWS_REGION` in `.env.local`.
